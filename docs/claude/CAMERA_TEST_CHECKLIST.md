### 3️⃣ 录制功能测试（完整流程）

#### 准备阶段

- [ ] **步骤1**：确保摄像头推流已启动
- [ ] **步骤2**：填写受试者编号（如：S001）
- [ ] **步骤3**：点击"采集"按钮
- [ ] **步骤4**：填写个人信息，点击"开始"

#### 采集阶段

- [ ] **步骤5**：等待采集开始（准备阶段）
- [ ] **步骤6**：**按下空格键（第一次）**
- [ ] **验证**：
  - [ ] 全屏白色闪烁显示"SYNC"
  - [ ] Toast提示"摄像头录制已启动 🎥"
  - [ ] 控制台输出：`[Collection] 🎥 第一个space按下，启动摄像头录制...`
  - [ ] 控制台输出：`[Collection] ✅ 摄像头录制已启动`

- [ ] **步骤7**：继续采集，再按2-3次空格键
- [ ] **验证**：不再提示"摄像头录制已启动"（已忽略）

- [ ] **步骤8**：等待采集自然结束，或手动点击"停止"
- [ ] **验证**：
  - [ ] 控制台输出：`[Collection] 🎥 停止摄像头录制...`
  - [ ] 控制台输出：`[Collection] ✅ 摄像头录制已停止`
  - [ ] 浏览器自动下载2个视频文件：
    - `S001_session1_{stage}_{timestamp}_left.webm`
    - `S001_session1_{stage}_{timestamp}_right.webm`

### 4️⃣ H5文件关联测试

- [ ] **步骤1**：找到生成的H5文件（在 `storage/` 目录下）
- [ ] **步骤2**：使用Python读取H5文件：

```python
import h5py

h5_file = 'storage/discrete_gesture/.../S001_session1_xxx.h5'

with h5py.File(h5_file, 'r') as f:
    print('=== H5文件信息 ===')
    print(f'文件路径: {h5_file}')
    print(f'\n=== 视频文件信息 ===')
    print(f'video_left: {f.attrs.get("video_left", "无")}')
    print(f'video_right: {f.attrs.get("video_right", "无")}')
    print(f'video_start_timestamp: {f.attrs.get("video_start_timestamp", "无")}')
    
    if 'prompts' in f:
        prompts = f['prompts'][:]
        print(f'\n=== Prompts信息 ===')
        for i, p in enumerate(prompts):
            name = p['name'].decode() if isinstance(p['name'], bytes) else p['name']
            print(f'  [{i}] {name}: {p["time"]:.6f}')
```

- [ ] **验证**：
  - [ ] `video_left` 存在且为视频文件名
  - [ ] `video_right` 存在且为视频文件名
  - [ ] `video_start_timestamp` 存在且为浮点数
  - [ ] 第一个space的prompt时间戳 ≈ `video_start_timestamp`（误差 < 1秒）

## 🐛 错误场景测试

### 场景1：未启动推流就开始采集

- [ ] **步骤**：不启动推流，直接开始采集并按space
- [ ] **验证**：Toast提示"摄像头未推流，无法录制"

### 场景2：采集过程中停止推流

- [ ] **步骤**：
  1. 启动推流
  2. 开始采集
  3. 按space启动录制
  4. 点击"停止推流"
- [ ] **验证**：录制自动停止

### 场景3：未按space就结束采集

- [ ] **步骤**：
  1. 启动推流
  2. 开始采集
  3. 不按space，直接停止采集
- [ ] **验证**：
  - [ ] 无视频文件下载
  - [ ] H5文件中无video_left/right属性
