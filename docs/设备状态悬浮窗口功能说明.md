# 设备状态悬浮窗口功能说明

## 功能概述

新增了一个悬浮在所有界面上方的设备状态显示窗口，实时显示左右手环的：
- **连接状态**（已连接/未连接）
- **电池电量**（百分比 + 动态图标）
- **流模式**（空闲/预览/采集中）

## 功能特点

### 1. 视觉设计
- **位置**：固定在屏幕右上角
- **样式**：半透明白色背景 + 毛玻璃效果
- **渐变头部**：紫色渐变标题栏
- **阴影效果**：柔和阴影提升层次感

### 2. 电池显示
电池图标和颜色根据电量自动变化：

| 电量范围 | 图标 | 颜色 |
|---------|------|------|
| 90%-100% | 满格电池 | 绿色 (#10b981) |
| 60%-89% | 3/4电池 | 黄绿色 (#22c55e) |
| 30%-59% | 1/2电池 | 黄色 (#eab308) |
| 10%-29% | 1/4电池 | 橙色 (#f59e0b) |
| 0%-9% | 空电池 | 红色 (#ef4444) |
| 未连接 | 空电池 | 灰色 (#cbd5e1) |

### 3. 连接状态
- **已连接**：绿色 + 脉冲动画（2秒循环）
- **未连接**：灰色

### 4. 流模式显示
- **空闲 (idle)**：灰色，无动画
- **预览 (preview)**：蓝色 + 慢速闪烁（1.5秒循环）
- **采集中 (collection)**：红色 + 快速闪烁（1秒循环）

### 5. 交互功能
- **收起/展开**：点击标题栏或右侧按钮可收起/展开窗口
- **收起状态**：只显示标题栏，节省屏幕空间

## 技术实现

### 后端解析（ble_server.py）

根据ESP32固件的BLE状态包结构解析电池电量：

```python
# 固件结构体 (ble_gatt.h)
typedef struct __attribute__((packed)) {
    uint8_t packet_type;           // 0
    uint8_t protocol_version;      // 1
    uint8_t reason_code;           // 2
    uint8_t gain_index;            // 3
    uint16_t sample_rate_hz;       // 4-5
    uint8_t shift_amount;          // 6
    uint8_t num_imus;              // 7
    uint16_t flags;                // 8-9
    uint8_t battery_percent;       // 10 ← 电池百分比
    uint8_t storage_state;         // 11
    ...
} ble_status_snapshot_t;
```

修改内容：
1. `DeviceState` 类添加 `battery_percent` 字段
2. 状态包解析时提取 `s[8]`（battery_percent）
3. `to_dict()` 方法返回电池信息

### 前端更新机制（ble_control.js）

```javascript
// 配置
const STATUS_UPDATE_INTERVAL = 5000;  // 每5秒更新一次状态

// 定时器
startHeartbeat() {
    // 心跳保持连接（30秒）
    setInterval(() => send({ action: 'ping' }), HEARTBEAT_INTERVAL);
    
    // 状态更新（5秒）
    setInterval(() => send({ action: 'status' }), STATUS_UPDATE_INTERVAL);
}

// 状态同步
updateDeviceState(deviceId, data) {
    // 更新本地状态
    BleState.devices[deviceId] = { ...data };
    
    // 同步到悬浮窗口
    window.deviceStatusWidget.updateDevice(deviceId, {
        connected: data.connected,
        battery_percent: data.battery_percent,
        stream_mode: data.stream_mode,
    });
}
```

## 使用说明

### 1. 查看设备状态
悬浮窗口会自动显示，无需手动操作。每5秒自动更新一次。

### 2. 收起/展开窗口
- 点击标题栏任意位置
- 或点击右上角的 `^` 按钮

### 3. 状态含义
- **连接状态**：显示手环是否通过蓝牙连接
- **电池电量**：显示手环当前剩余电量百分比
- **流模式**：
  - 空闲：设备已连接但未采集数据
  - 预览：设备正在发送预览流数据
  - 采集中：设备正在采集并保存数据到SD卡

## 注意事项

1. **电池数据来源**：电池百分比由ESP32固件通过BLE STATUS特征上报
2. **更新频率**：每5秒自动更新，无需手动刷新
3. **浏览器兼容性**：需要支持CSS `backdrop-filter`（毛玻璃效果）
4. **设备识别**：设备1=左手，设备2=右手（根据连接顺序）

## 问题排查

### 问题1：悬浮窗口不显示
- 检查 `device-status-widget.js` 是否正确加载
- 打开浏览器控制台查看是否有JavaScript错误

### 问题2：电量显示为 "--"
- 确认设备已连接
- 确认固件版本支持电池状态上报
- 检查 `ble_server.py` 是否正确解析STATUS包

### 问题3：状态不更新
- 确认WebSocket连接正常（8764端口）
- 检查浏览器控制台是否有 `[BLE] 发送命令: {action: 'status'}` 日志
- 确认状态更新定时器正在运行
