# 双手动捕数据支持 - 修改记录

## 修改日期
2026-03-14

## 需求背景
原系统只支持单手动捕数据采集和显示，需要扩展为支持双手（左手/右手）独立采集、标定和显示。

## 需求详情

### 1. 后端数据处理
- **mocap_server.py**: 更新 marker 名称，左右手各10个marker点，分别计算左右手的通道值
- **storage_server.py**: 将原来的单个 `mocap` 数据集改为 `mocap_L` 和 `mocap_R` 两个独立数据集

### 2. 前端数据流
- **realtimeEngine.js**: 适配新的双手数据结构，删除 `continual_gesture_3` 相关代码

### 3. 动画输入接口
- **animation-input-interface.js**: 支持双手输入，提供两个独立的归一化值（左手/右手）

### 4. 动画显示
- **continual-gesture-1-animation.js**: 双光标显示（红色=左手，蓝色=右手）
- **continual-gesture-2-animation.js**: 双光标显示（红色=左手，蓝色=右手）

### 5. 标定界面
- **calibration-guide-animation.js**: 标定时实时显示左右手原始值

### 6. 清理
- 删除 `continual-gesture-3` 相关引用（该功能已废弃）

## 修改文件清单

### 后端文件

#### 1. mocap_server.py
**修改内容：**
- Marker 名称从 `TH1, TH2...` 改为带后缀的 `TH1_L, TH1_R...`
- 左手 marker: `TH1_L, TH2_L, TH3_L, TH4_L, ID1_L, ID2_L, ID3_L, HB1_L, HB2_L, HB3_L`
- 右手 marker: `TH1_R, TH2_R, TH3_R, TH4_R, ID1_R, ID2_R, ID3_R, HB1_R, HB2_R, HB3_R`
- 通道计算函数 `calculate_finger_joint_angle()` 和 `calculate_thumb_index_distance()` 增加 `hand` 参数
- 输出通道改为：
  - `finger_joint_angle_L` / `finger_joint_angle_R`
  - `thumb_index_distance_L` / `thumb_index_distance_R`

#### 2. storage_server.py
**修改内容：**
- 定义 `MOCAP_L_DTYPE` 和 `MOCAP_R_DTYPE` 两个数据类型
- 创建 `mocap_L` 和 `mocap_R` 两个独立数据集
- `_append_mocap_batch()` 方法分别写入左右手数据
- 统计信息改为 `mocap_L_frames` 和 `mocap_R_frames`

### 前端文件

#### 3. realtimeEngine.js
**修改内容：**
- `onTaskChange()` 中删除 `continual_gesture_3` 的通道映射
- 通道映射只保留：
  ```javascript
  'continual_gesture_1': 'finger_joint_angle',
  'continual_gesture_2': 'thumb_index_distance'
  ```

#### 4. animation-input-interface.js
**修改内容：**
- 新增双手原始值：`rawValue_L`, `rawValue_R`
- 新增双手归一化值：`normalizedValue_L`, `normalizedValue_R`
- 新增双手平滑值：`_smoothedValue_L`, `_smoothedValue_R`
- 标定状态扩展为双手独立：
  ```javascript
  calibration: {
    rawValues_L: [], min_L: null, max_L: null, isCalibrated_L: false,
    rawValues_R: [], min_R: null, max_R: null, isCalibrated_R: false,
    // ... 兼容旧接口
  }
  ```
- 新增方法：
  - `getNormalizedInputDual()` - 返回 `{left, right}`
  - `getRawInputDual()` - 返回 `{left, right}`
  - `getMappedInputDual(min, max)` - 返回 `{left, right}`
- `onMocapData()` 解析 `channelName_L` 和 `channelName_R`
- `_updateNormalizedValue()` 分别计算左右手归一化值
- `_calculateCalibrationRange()` 提取为独立方法，供左右手分别调用

#### 5. continual-gesture-1-animation.js
**修改内容：**
- 新增双手半径：`userRadius_L`, `userRadius_R`
- 新增双手跟踪数据：`trackingData_L`, `trackingData_R`
- 新增双手精度统计：`trialAccuracy_L`, `trialAccuracy_R`
- 颜色配置扩展：
  ```javascript
  colors: {
    userCircle_L: '#ef4444',      // 红色（左手）
    userCircleBorder_L: '#991b1b',
    userCircle_R: '#3b82f6',      // 蓝色（右手）
    userCircleBorder_R: '#1d4ed8',
    // ...
  }
  ```
- `isOnTarget(hand)` 方法增加 `hand` 参数
- 新增 `drawUserCircles()` 方法绘制双手圆
- 新增 `_drawSingleUserCircle()` 方法绘制单个用户圆
- `animate()` 方法从 `inputInterface.getNormalizedInputDual()` 获取双手数据
- `drawProgress()` 显示双手状态信息
- 左手标记在圆顶部，右手标记在圆底部（避免重叠）

#### 6. continual-gesture-2-animation.js
**修改内容：**
- 与 `continual-gesture-1-animation.js` 完全相同的双手支持修改

#### 7. calibration-guide-animation.js

## 数据结构变化

### H5 文件结构（storage_server.py）

**旧结构：**
```
/mocap          # 单个数据集，包含所有marker
```

**新结构：**
```
/mocap_L        # 左手数据集
  - TH1_L, TH2_L, TH3_L, TH4_L  # 拇指
  - ID1_L, ID2_L, ID3_L          # 食指
  - HB1_L, HB2_L, HB3_L          # 手背
  - frame, time

/mocap_R        # 右手数据集
  - TH1_R, TH2_R, TH3_R, TH4_R  # 拇指
  - ID1_R, ID2_R, ID3_R          # 食指
  - HB1_R, HB2_R, HB3_R          # 手背
  - frame, time
```

### WebSocket 数据格式（mocap_server.py → realtimeEngine.js）

**旧格式：**
```json
{
  "channels": {
    "finger_joint_angle": {"value": 45.0},
    "thumb_index_distance": {"value": 50.0}
  }
}
```

**新格式：**
```json
{
  "channels": {
    "finger_joint_angle_L": {"value": 45.0},
    "finger_joint_angle_R": {"value": 42.0},
    "thumb_index_distance_L": {"value": 50.0},
    "thumb_index_distance_R": {"value": 48.0}
  }
}
```

## 界面变化

### 连续手势动画
- 原来：单个用户圆（红色）
- 现在：两个用户圆
  - 左手圆：红色，标记点在顶部，显示"左"
  - 右手圆：蓝色，标记点在底部，显示"右"

### 标定界面
- 新增"实时原始值"显示区域
- 左手值：红色显示
- 右手值：蓝色显示
- 每100ms更新一次

### 进度信息
- 原来：`用户: 75 | 引导: 80 | 误差: -5`
- 现在：`引导: 80 | 左手: 75 (误差:-5) | 右手: 78 (误差:-2)`

## 兼容性说明

所有修改都保留了旧接口的兼容性：
- `rawValue` = `rawValue_L`（取左手值）
- `normalizedValue` = `normalizedValue_L`
- `calibration.isCalibrated` = `isCalibrated_L && isCalibrated_R`
- `getNormalizedInput()` 仍然可用，返回左手值
- `drawUserCircle()` 仍然可用，内部调用 `drawUserCircles()`
